# Security Policy

This is the Next.js frontend for ContextQuery — it calls the backend API and does not itself hold API keys or execute untrusted code.

## Scope

- XSS or injection issues in how documents, queries, or citations are rendered
- Any path where backend credentials or internal URLs could leak to the client

## Reporting

This is a personal/portfolio project. If you find an issue, please open a GitHub issue on this repo, or contact me directly via the email in my GitHub profile for anything you'd rather not disclose publicly first.
